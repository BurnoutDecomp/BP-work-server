XBOX 360 / THE XDK AGAINST ARTIST

Byte matching.

·

The native Xbox 360 tree (b5-decomp x360) compiled with the console's own XDK compiler and compared with the shipped game, function by function. Exact means the same bytes outside the fields the linker fills in, with the same callees and constants. Contributors measure where the XDK is installed; every push to the branch or to the records refreshes this panel.

    CONSOLE AUDITS / LEADS, NOT VERDICTS

    Console gaps.

    ·

    What the console's code does that our PC code does not yet: switch cases with no arm, events never posted, calls never made, functions with no body, and bodies that are still stand-ins. CI compares every reconstructed body with the console's pseudocode on each decomp commit. Each gap is a lead to check, not a verdict.
